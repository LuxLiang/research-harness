# Failure taxonomy

Report the most specific class supported by evidence. Do not select a workflow state.

- Runtime: `TOOL_UNAVAILABLE`, `TIMEOUT`, `RESOURCE_EXHAUSTED`, `PERMISSION_DENIED`.
- Concurrency/input: `REVISION_CONFLICT`, `CHECKPOINT_CONFLICT`, `INPUT_INCOMPLETE`, `CONTEXT_LIMIT`, `VALIDATION_FAILED`.
- Novelty: `NOVELTY_KNOWN`, `NOVELTY_EQUIVALENT`, `NOVELTY_UNCERTAIN`, `SOURCE_UNVERIFIED`.
- Theory/formal: `PROOF_GAP`, `ASSUMPTION_GAP`, `DEPENDENCY_GAP`, `FALSE_CLAIM`, `FORMALIZATION_GAP`, `LIBRARY_GAP`, `LEAN_PROOF_GAP`, `SORRY_FOUND`, `UNAPPROVED_AXIOM`, `SEMANTIC_MISMATCH`.
- Experiment/evidence: `PROTOCOL_GAP`, `PROTOCOL_DEVIATION`, `IMPLEMENTATION_FAILURE`, `REPRODUCIBILITY_FAILURE`, `STATISTICAL_INSUFFICIENCY`, `DATA_LEAKAGE`, `SELECTIVE_REPORTING`.
- Synthesis/writing: `EVIDENCE_GAP`, `UNRESOLVED_CONTRADICTION`, `STALE_EVIDENCE`, `TRACEABILITY_GAP`, `CITATION_FAILURE`, `OVERCLAIM`.

GateService maps these classes deterministically to retries, typed rethink, follow-up, or BLOCKED.
